Project Overview

This project utilizes Machine Learning to predict diseases based on user symptoms. By leveraging advanced models like Random Forest, the system accurately identifies potential diseases and provides users with reliable precautionary measures.

How It Works?

The system collects user symptoms and processes them through a trained machine learning model. It then predicts the most likely disease and provides a list of recommended precautions to help users take the necessary steps toward recovery.

Machine Learning Approach

Various algorithms like Decision Tree, SVM, K-Nearest Neighbor, Logistic Regression, Random Forest, and Naïve Bayes were tested. Among them, Random Forest was chosen due to its high accuracy, efficiency, and ability to handle complex data.

Precautionary Measures

Our system not only predicts diseases but also provides personalized precautions. These include home remedies, diet recommendations, and necessary medical attention to ensure early-stage care and prevention.
